# guzhuang-intimacy-storyboard

古装风格含蓄内敛的亲密戏分镜与动作设计技能（Agent Skill）。

## 简介

本技能专门用于设计古装题材中含蓄、内敛、有意境的亲密/情欲场景。它将情欲转化为可执行的镜头语言、动作表与氛围设计，重点放在衣冠层次、发丝、眼神、手部、呼吸与环境象征，而非直白身体接触。

适用于：
- 古装剧、电影、短片的情欲戏设计
- AI 生图 / 生视频的提示词与镜头规则
- 需要“点到为止”而非直白暴露的分镜
- 给演员、导演或亲密协调员参考的含蓄动作表

## 核心特点

- 以衣冠、发丝、眼神传情
- 强调留白、遮挡与仪式感
- 节奏缓慢，注重情绪递进
- 环境（烛火、月光、纱帐、雨声等）参与叙事
- 默认保持含蓄尺度

## 使用方法

将本仓库中的技能文件放入支持 `SKILL.md` 的 Agent 环境中（如 Cursor、Claude Code 等）即可调用。

### 触发示例

- “按古装含蓄风格给我做这场亲密戏的分镜”
- “帮我设计一场内敛的古装情欲戏动作表”
- “用衣带和眼神来表现这场做爱”
- “雨夜闺房，含蓄缠绵的分镜”

调用时建议提供：
- 人物关系
- 场景环境
- 情绪基调
- 期望的含蓄程度

## 输出内容

技能会按标准格式输出：
- 场景意境描述
- 情绪节拍
- 含蓄动作与分镜表
- 氛围与技术建议
- AI 生图/生视频提示词要点
